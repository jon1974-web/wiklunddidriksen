1. Introduksjon

Familiesenter er en familieapp som hjelper familier med å organisere hverdagen. Vi tar personvern på alvor og denne personvernpolicyen forklarer hvordan vi samler inn, bruker og beskytter dataene dine.

2. Dataansvarlig

Jon Wiklund Didriksen
jon@wiklunddidriksen.com

3. Data vi samler inn

Konto og profil

  • E-postadresse
  • Visningsnavn
  • Telefonnummer (valgfritt)
  • Profilbilde (valgfritt)

Familie

  • Familienavn
  • Familieroller (eier, admin, medlem)
  • Invitasjonskoder

Helse

  • Medisiner, timer, vaksiner, allergier, vekst
  • Disse dataene er spesielt beskyttet under GDPR artikkel 9

Skole

  • Barns navn og skoleinformasjon
  • Kontakter (lærere, klassekamerater, foresatte)
  • Timeplaner

Reiser

  • Reiser, transport, overnatting, restauranter, aktiviteter

Chat

  • Meldinger, bilder, reaksjoner

4. Hvordan vi bruker dataene dine

  • Drifte og forbedre appen
  • Gi deg tilgang til familiens data
  • Send påminnelser om avtaler
  • AI-funksjoner (oppskrifter, stemme-til-arrangement, foto-til-arrangement)
  • Synkronisere med tredjepartstjenester (Spond, Google Calendar)

6. Lagring og sikkerhet

  • AES-256-kryptering for Spond-passord
  • Google-håndtert kryptering for øvrige data
  • TLS-kryptering under overføring
  • Familiscoped Firestore-regler
  • Daglige automatiserte backups (30 dagers lagring)

7. Dine rettigheter

  • Innsyn: Du kan se alle data vi har om deg
  • Retting: Du kan korrigere feilaktige data
  • Sletting: Du kan slette kontoen din
  • Dataportabilitet: Du kan eksportere dataene dine
  • Samtykke: Du kan trekke tilbake samtykke når som helst

8. Barns data

Appen samler inn data om barn (navn, skoleinformasjon, kontakter). Disse dataene er underlagt strenge beskyttelsesregler. Foreldre/verger har full kontroll over barnas data.
